# Static Packet Filtering

A type of [[Packet Filtering Firewall]] that uses pre-defined, manually configured rules.

## Characteristics
- Requires rules to be developed and installed with the firewall
- Any changes are to be done by human intervention
- Common and easy to setup
- Static allow entire set of one type of packets to enter in response to authorized requests

## Advantages
- Simple to configure
- Low computational overhead
- Predictable behavior

## Limitations
- Inflexible - cannot adapt to new threats automatically
- Requires manual updates to rule sets
- No context awareness
- Cannot respond to emerging attack patterns

## Comparison
Unlike [[Dynamic Packet Filtering]] or [[Stateful Packet Inspection]], static filtering does not maintain session information or automatically adapt rules.
