## Security Threats on Mobile Devices

| Concern                         | Risk                                                              |
| ------------------------------- | ----------------------------------------------------------------- |
| Lack of Physical Security       | Devices can be lost or stolen                                     |
| Untrusted Mobile Devices        | Personal devices may bypass security policies of the Organization |
| Untrusted Networks              | Public WIFI or cellular network pose a threat to MitM             |
| Untrusted Applications          | Third party apps may steal                                        |
| Interactions with Other Systems | Auto-sync spreads malware                                         |
| Untrusted Content               | QR codes/link may redirect to malicious websites                  |
| Location Services               | GPS data may be used by attackers                                 |

## Security Countermeasures for Mobile Devices

| Countermeasures                  | Description                                                                                   |
| -------------------------------- | --------------------------------------------------------------------------------------------- |
| Device Access protection         | Enable auto-lock, passwords/pins and biometrics authentication. Encrypt mails and stored data |
| Data Security                    | Prohibit storage of sensitive data or make sure its encrypted                                 |
| Network and application security | ensure encrypted (SSL/TLS) communication medium, Keep applications up-to-date                 |
| User awareness and training      | Train dumb employees especially boomers                                                       |
