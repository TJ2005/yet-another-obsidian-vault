
## Security Threats

| Threat                            | Description                                                                                                                                                            |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Accidental Association            | Overlapping transmission ranges between company WLANs or APs expose resources unintentionally e.g. Employee's laptop gets accidently connected to nearby office's WIFI |
| Malicious Association             | A rogue user acts as a legitimate AP e.g. Attacker sets up a fake WIFI access point                                                                                    |
| AD hoc & Non Traditional Networks | peer-to-peer wireless networks or devices like Bluetooth create risks of eavesdropping and spoofing.                                                                   |
| Identity Theft                    | Attacker spoofs legitimate MAC addresses to gain unauthorized access                                                                                                   |
| MitM                              | Attacker intercepts and manipulates communication between a client and an AP                                                                                           |
| DoS                               | Denial of Service is when an AP gets flooded with unwanted requests exhausting resources and halting services                                                          |
| Network Injection                 | Malicious management/routing messages to reconfigure APs.                                                                                                              |

## Security Countermeasures

| Countermeasures                | Description                                                           |
| ------------------------------ | --------------------------------------------------------------------- |
| Securing Wireless Transmission | Use Strong authentication, firewalls, IDPS to protect data in transit |
| Signal Hiding Techniques       | Don't broadcast SSID                                                  |
| Encryption                     | Use Strong Encryption to prevent eavesdropping                        |
| Securing Wireless AP           | Access points can be misused and misconfigured by attackers           |
| Securing Wireless Networks     | Use encryption like WPA3                                              |
|                                |                                                                       |
