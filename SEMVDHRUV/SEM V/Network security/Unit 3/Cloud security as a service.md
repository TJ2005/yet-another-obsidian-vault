## Sec-aaS ( Security as a Service)

Security delivered as a cloud-based subscription model. Characteristics are as follows :

- Scalable
- On Demand
- Low Investment Cost
- Reduces cost while Offering Enterprise Grade Security

## Core Features

- IAM
- Data Loss Prevention
- Web and Mail Security
- IDPS
- SIEM ( Security Information and Event Manager )


---
## IAM 

Identity Access management (IAM) System to make sure that only the right people get in, and only to the areas they are allowed.

- Verifies who you are
- Grants you access based on the ID
- Ensures Trusted User Profiles
- Consistently Applies Access Rules
- Guarantees 
	- Security
	- Transparency 
	- Trust
---
## Data Loss Prevention

Data can either be at Rest, Motion or Use. Data Loss Prevention monitors these states of the Data and tries to prevent Data Loss.

- Can block downloading of key Sensitive Files
- Detect and stop attempts to upload sensitive data to unapproved cloud services

 Example: Preventing employees from copying confidential customer data to USB drives or emailing it outside the company.
 
---
## Email Security

Provides control over inbound and outbound emails protecting the organization from various attacks

- Phishing
- Spam Prevention

Enforces Various policies such as digital signatures etc.

## Security Audits

While this service is outside the province of the CSP, the CSP can provide tools and access points to facilitate various assessment activities. We basically Evaluate the fitness of the service in the context of cloud security.

---
## IDPS

The core of this service is the implementation of intrusion detection systems (IDSs) and intrusion prevention systems (IPSs) at entry points to the cloud and on servers in the cloud.

An IDS is a set of automated tools designed to detect unauthorized access to a host system.

Example : If someone tries to access a company’s database without permission, IDS alerts the admin, and IPS blocks the attempt

---
## SIEM

SIEM tools collect, analyze, and correlate logs and event data from both virtual and real networks, applications, and systems. They provide real-time alerts and reports, enabling quick responses to potential security incidents. 

Example : Windows Event Manager

---

## Encryption

Encryption is a core security service that protects

- Data at rest in the cloud 
- Email traffic 
- Client-specific network information 
- User identity detail

VPN (Virtual Private Network) setup, application-level encryption, and secure access to data.
