Object oriented system is made up of
- Interacting Objects
- Designing Object classes 
- The relationship between these classes
- Objects are associated with things

## Brief
 Design is not a straight sequence; you move back and forth refining ideas.
 
- Example: a wilderness weather station that collects data and sends it via satellite.
- Before designing, understand how the system fits into its environment.
- This helps define system boundaries and what responsibilities belong inside vs. outside the system.

- **System context model:** shows external entities connected to the system (structural view).  
- **Interaction model:** shows how the system exchanges information with those entities (dynamic view).

## Key Terms
These terms will help you understand.
- **Cardinalities:** This helps u understand the number of items in a specific relationship.
- **Relationship:** Understand the relationship between two objects. External or Internal.
