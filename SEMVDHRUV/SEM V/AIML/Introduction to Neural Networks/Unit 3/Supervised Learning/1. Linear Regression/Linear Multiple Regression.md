## Multiple Linear Regression

### Definition  
Multiple regression is used to estimate the relationship between two or more independent variables and one dependent variable.  
It is a statistical technique that uses several predictors to model and forecast the outcome of a response variable.

### Assumptions  
- There is a linear relationship between each independent variable and the dependent variable  
- Residuals are normally distributed  
- Independent variables are not highly correlated (no multicollinearity)

### General Form  

$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_n X_n + \varepsilon$$
Where  
$Y$ is the dependent variable  
$X_1, X_2, \dots, X_n$ are independent variables  
$\beta_0$ is the intercept  
$\beta_1, \beta_2, \dots, \beta_n$ are the coefficients  
$\varepsilon$ is the error term
