# Data Quality

To ensure that the data is accurate, complete, consistent and reliable. High quality data helps in making accurate predictions while poor data leads to errors biased, unexpected outcomes.

# Characteristics

**Completeness:** Is a measure of whether all of the required data is present within the dataset and if it meets the objectives
**Accuracy:** Is a measure of how well the data accurately reflects the object being described.
**Timeliness:** Is a measure of data being available when its needed for decision making.
**Consistency:** Is a measure of how consistent the data is
**Validity:** Is a measure of how well the data fits within pre-defined limits, expectations, and standards
	**Uniqueness:** Features or Objects should only be represented within a particular dataset only once.
