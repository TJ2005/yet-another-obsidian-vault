## Introduction

MITRE ATT&CK is a knowledge base of adversary tactics and techniques based on real-world observations. It is used for threat modeling, detection, and defense strategies.

## Structure

1. **Tactics**  
    High-level objectives of attackers. Examples: Initial Access, Execution, Persistence, Privilege Escalation, Defense Evasion, Credential Access, Discovery, Lateral Movement, Collection, Command and Control, Exfiltration, Impact.
    
2. **Techniques**  
    Specific methods adversaries use to achieve tactics. Example: Spearphishing for Initial Access, Process Injection for Defense Evasion.
    
3. **Sub-techniques**  
    More detailed descriptions of how techniques are carried out. Example: Spearphishing Attachment vs. Spearphishing Link.
    
4. **Procedures**  
    Real-world implementations of techniques by threat groups or malware.

## Use Cases

1. Threat Intelligence: Mapping adversary behavior to ATT&CK techniques.
2. Detection and Monitoring: Building alerts and analytics based on known techniques.
3. Red Teaming: Designing realistic attack simulations.
4. Blue Teaming: Improving defenses and incident response.
5. Gap Analysis: Identifying missing controls or visibility in security systems.

## Benefits

1. Standardized language for describing attacker behavior.
2. Improves collaboration between security teams.
3. Enables measurable security maturity assessments.
4. Provides a living framework updated with new adversary techniques.
