# Firewall Processing Modes

[[Firewalls Overview|Firewalls]] can be classified based on how they process traffic to block or allow it.

![Firewall Processing Modes](https://i.sstatic.net/RVAeW.png)

## Types of Processing Modes

1. [[Packet Filtering Firewall|Packet Filtering]]
2. [[Application Layer Proxy Firewall|Application Layer Proxy Firewall]]
3. [[MAC Layer Firewall|Media Access Control (MAC) Layer Firewall]]

Each processing mode operates at different layers of the [[OSI Model]] and has distinct characteristics and use cases.
