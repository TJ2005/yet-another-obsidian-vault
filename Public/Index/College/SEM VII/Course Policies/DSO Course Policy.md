# DevSecOps - Course Policy

| Field | Information |
| --- | --- |
| Code | 702IT0E031 |
| Teaching scheme | 2 lectures + 2 practical hours/week |
| Credits | 3 |
| Evaluation | ICA 50; TEE 100 scaled to 50 |
| Prerequisite | Fundamental knowledge of cybersecurity and software engineering |
| Laboratory work | 8 to 10 exercises based on the syllabus |

## Course Objective

Integrate security throughout Agile and DevOps processes, with practical emphasis on DevSecOps tools, Docker containers and Kubernetes security, monitoring and administration.

## Units

| Unit | Title | Duration | Contents |
| --- | --- | ---: | --- |
| 1 | DevOps | 6 hours | SDLC, Agile, Scrum, need and advantages, principles, CAMS, lifecycle and the 7Cs. |
| 2 | DevSecOps | 8 hours | Need, lifecycle, methodologies, continuous integration and continuous delivery. |
| 3 | DevSecOps Tools | 5 hours | Vagrant, Git, Jenkins, SAST, DAST, dependency analysis, IaC security, secrets, vulnerabilities, alerts and monitoring. |
| 5 | Docker and Kubernetes Security | 5 hours | Principles, best practices, auditing, vulnerability analysis and monitoring. |
|  | **Printed total** | **30 hours** | The source skips Unit 4, and the listed durations add up to 24 hours. |
