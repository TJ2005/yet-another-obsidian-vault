# Capstone Project - Course Policy

| Field | Information |
| --- | --- |
| Code | 702EE0C002 |
| Teaching scheme | 8 practical hours/week |
| Credits | 4 |
| Evaluation | ICA 50; presentation and viva 50 |
| Prerequisite | Knowledge of all core and elective courses completed through the third year |

## Course Objective

Provide a culminating design experience in which students think critically, solve a challenging problem, study feasibility, manage teamwork, and demonstrate written and oral communication.

## Project Requirements

| Stage | Duration | Information |
| --- | ---: | --- |
| Project work | Throughout the semester | Select a problem after literature review and gap identification; formulate use cases or a feasible design model. |
| Implementation | Throughout the semester | Develop a prototype or proof of concept; test and validate results; manage the team project. |
| Report | End of semester | Document literature review, problem formulation, analysis, simulation/synthesis, work plan and completed work. |
| Presentation and viva | End of semester | Present and defend the completed work before examiners. |
