# Cyber Physical Systems Security - Course Policy

| Field | Information |
| --- | --- |
| Code | 702IT0E030 |
| Teaching scheme | 2 lectures + 2 practical hours/week |
| Credits | 3 |
| Evaluation | ICA 50; TEE 100 scaled to 50 |
| Prerequisite | Fundamental knowledge of cybersecurity |
| Laboratory work | 8 to 10 exercises based on the syllabus |

## Course Objective

Introduce security issues affecting cyber-physical systems, industrial control systems and critical infrastructure.

## Units

| Unit | Title | Duration | Contents |
| --- | --- | ---: | --- |
| 1 | Cyber Physical Systems | 3 hours | Emergence, applications, concepts and principles. |
| 2 | Security and Privacy for CPS | 4 hours | Objectives, attacks, threats, modelling, detection, architecture and mitigation. |
| 3 | Key Management in CPS | 3 hours | Security goals, threat model, design principles, key management, challenges and research issues. |
| 4 | Industrial Control Systems | 5 hours | ICS architecture, SANS ICS410 reference model, Purdue model, attacks and mitigation. |
| 5 | Software Defined Networks | 5 hours | SDN introduction, security and privacy leakages. |
| 6 | CPS Security and Privacy Case Studies | 10 hours | IoT, smart homes/buildings, smart grid, vehicles, wearables, BYOD and mobile healthcare. |
|  | **Total** | **30 hours** |  |
