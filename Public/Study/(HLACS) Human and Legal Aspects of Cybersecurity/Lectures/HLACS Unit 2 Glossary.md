# HLACS Unit 2 Glossary

> [!ABSTRACT] Fixed, exam-ready definitions — keyword-focused.

| Term | Definition |
| --- | --- |
| **Culture** | Cumulative deposit of knowledge, experience, beliefs, values, attitudes, meanings and material possessions acquired by a group across generations through individual and group striving |
| **Cybersecurity Culture (CSC)** | The knowledge, beliefs, perceptions, attitudes, assumptions, norms and values regarding cybersecurity — and how they **manifest in behaviour** with information technologies |
| **Embeddedness** | Security considerations made an integral part of an employee's job, habits and day-to-day conduct |
| **Attitude** | Dimension — feelings and beliefs toward security protocols and issues |
| **Behaviours** | Dimension — actions with direct or indirect impact on organisational security |
| **Cognition** | Dimension — understanding, knowledge and awareness of security issues |
| **Communication** | Dimension — quality of channels to discuss security topics and report incidents |
| **Compliance** | Dimension — knowledge of written policies **and the extent they are followed** |
| **Responsibilities** | Dimension — perceiving one's own role as critical to sustaining or endangering security |
| **Norms** | Dimension — adherence to **unwritten rules** of conduct |
| **Shared responsibility** | Security owned by every employee, not a single department |
| **MFA push fatigue** | Attack flooding a target with MFA prompts until an exhausted "Accept" (Uber 2022) |
| **Spear phishing** | Targeted phishing aimed at a specific high-value person |
| **Personal access token (PAT)** | Persistent credential for programmatic access (e.g., GitHub) — compromise = standing admin access |
| **Static analysis** | Automated code scanning in CI/CD that insecure cultures bypass under deadline pressure |
| **CI/CD pipeline** | Continuous integration/deployment chain — build → test → production |
| **MFA exemption list** | Deliberate removal of second-factor checks for privileged users — a single point of failure |
| **Privileged access** | Rights exceeding normal users (admins); highest-value insider target |
| **Insider target logic** | Attackers select employees by access + exposure (CFO travels, HR holds databases, IT has privileges) |
