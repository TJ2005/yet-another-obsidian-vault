# HLACS Unit 1 Glossary

> [!ABSTRACT] Fixed, exam-ready definitions — keyword-focused.

| Term                                          | Definition                                                                                                                                   |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Human element**                             | People as the decisive factor in security — they choose, configure, operate and respond; technology alone cannot secure an organisation      |
| **Security–Usability–Functionality triangle** | Trade-off model: strengthening one corner weakens the others                                                                                 |
| **SETA**                                      | Security Education, Training and Awareness — NIST SP 800-50 program addressing the human element across three learning levels                |
| **Security awareness**                        | Focusing attention on security so individuals recognise concerns and respond; changes behaviour, but is *not* training                       |
| **Security training**                         | Teaching skills/competencies to perform a specific function (functional specialists, not IT-security staff)                                  |
| **Security education**                        | Integrating all security skills into a common body of knowledge + multidisciplinary study → produces security professionals                  |
| **Centralised model (1)**                     | SETA policy, strategy and implementation all centralised                                                                                     |
| **Partially decentralised model (2)**         | Centralised policy + strategy; distributed implementation                                                                                    |
| **Fully decentralised model (3)**             | Centralised policy only; strategy + implementation distributed                                                                               |
| **Needs assessment**                          | Structured information gathering (interviews, surveys, metrics, event analysis) to determine awareness/training requirements                 |
| **Setting the bar**                           | Matching material complexity to attendee position and required security skills                                                               |
| **Knowledge–Intention–Behaviour gap**         | Awareness/information does not automatically produce behaviour change                                                                        |
| **Behaviour shaping / Culture shaping**       | Transformational SETA goals — high effort, transformational benefit (vs compliance/info dissemination: limited benefit, low effort)          |
| **System 1 thinking**                         | Fast, emotional, intuitive thought based on heuristics (~95% of thinking)                                                                    |
| **System 2 thinking**                         | Slow, methodical, logical, deliberate reasoning                                                                                              |
| **Heuristic**                                 | Mental shortcut / rule of thumb enabling quick judgments                                                                                     |
| **Bias**                                      | Systematic error in reasoning producing wrong decisions                                                                                      |
| **Event-based decision making**               | Reactive/tactical responses to trigger events (alerts, IoCs, threshold rules); metric = MTTD/MTTR                                            |
| **Risk-based decision making (RBCRM)**        | Proactive/strategic evaluation through business context — likelihood × impact vs mitigation cost; metric = expected loss, risk-reduction ROI |
| **SOAR**                                      | Security Orchestration, Automation and Response — playbook automation suited to event-based response                                         |
| **Alert fatigue**                             | Desensitisation from high false-positive noise in event-driven operations                                                                    |
| **Black swan event**                          | Low-likelihood, high-impact incident missed by risk models with outdated data                                                                |
| **Hybrid standard**                           | Using risk context to filter and prioritise event-based responses                                                                            |
| **IoC**                                       | Indicator of Compromise — observed artifact signalling potential intrusion                                                                   |
| **Security fatigue**                          | Threshold at which maintaining security becomes too burdensome → desensitisation and weariness (Furnell & Thomson)                           |
| **Affect heuristic**                          | Emotion-of-the-moment drives risk/benefit judgment                                                                                           |
| **Anchoring bias**                            | Over-reliance on the first piece of information received                                                                                     |
| **Availability heuristic**                    | Judging likelihood by ease of recall from memory/experience                                                                                  |
| **Confirmation bias**                         | Seeking/favouring evidence confirming existing beliefs                                                                                       |
| **Optimism bias**                             | Belief "this won't happen to me"; ~80% exhibit it                                                                                            |
| **Framing effect**                            | Decisions altered by presentation of identical facts                                                                                         |
| **Dunning–Kruger effect**                     | Unskilled overestimate their ability; experts underestimate theirs                                                                           |
| **Sunk cost fallacy**                         | Escalating investment based on past investment despite contrary evidence (irrational escalation)                                             |
| **ADDIE**                                     | Analysis, Design, Development, Implementation, Evaluation — instructional design cycle for training programs                                 |
| **Learning pyramid**                          | Retention ladder: reading 10% → audiovisual 20% → discussion 50% → practice 75% → teaching others 90%                                        |
| **Keller's ARCS**                             | Motivation design: Attention, Relevance, Confidence, Satisfaction                                                                            |
