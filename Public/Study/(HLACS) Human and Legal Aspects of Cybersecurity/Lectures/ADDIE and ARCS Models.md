# ADDIE and ARCS Models

> [!INFO] Purpose
> Instructional-design frameworks for building [[SETA Program|SETA]] and training programs that actually change behaviour.

## ADDIE model

| Phase              | Core activities                                                                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Analysis**       | Identify training need (e.g., low sales numbers) <br>define learning objectives <br>identify target audience<br>evaluate existing resources and gaps                      |
| **Design**         | Training plan (methods + materials) <br>create instructional content <br>define assessment methods/evaluation tools <br>schedule & logistics (sessions, duration, timing) |
| **Development**    | Produce visuals/videos/multimedia <br>build interactive elements (role-playing) <br>review content with stakeholders <br>pilot test → revise                              |
| **Implementation** | Deliver sessions <br>support and feedback during training <br>monitor learner progress <br>resolve issues live                                                            |
| **Evaluation**     | Gather effectiveness feedback <br>analyse assessment results for gaps <br>compare before/after metrics (sales numbers) <br>modify based on results                        |

### Advantages vs limitations

| Advantages | Limitations |
| --- | --- |
| Adaptability | Linear process |
| Consistency | Resource-intensive |
| Iteration opportunities | Lack of emphasis on user experience |
| Built-in evaluation component | |

## Keller's ARCS model of motivation

| Element          | Techniques                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Attention**    | Active participation <br>humour <br>conflict <br>real-world examples                                               |
| **Relevance**    | Link to previous experience <br>perceived present worth <br>perceived future usefulness                              |
| **Confidence**   | Facilitate self-growth <br>communicate objectives and prerequisites <br>provide feedback <br>give learners control |
| **Satisfaction** | Praise or rewards <br>immediate application                                                                            |
