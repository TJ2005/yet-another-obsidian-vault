# Unsupervised Learning

Unsupervised Learning is a machine learning approach where the model learns **without supervision**.
During training, the machine is provided with **input data only**, without any corresponding output labels.
The goal is for the model to **identify hidden patterns, relationships, or structures** within the data on its own.

---

## Identifying Unsupervised Learning

A model uses unsupervised learning if the following conditions are true:

* The dataset used for training is **unlabeled**.
* The model tries to **find structure** or **grouping** in the data without known outcomes.
* It focuses on understanding the **distribution** and **relationships** among data points.

In essence, the model **learns from the data itself** rather than from predefined answers.

> [!tip] **Example**
>
> Consider a dataset containing information about customers’ purchasing habits — but without any labels.
> An unsupervised learning algorithm (like *K-Means Clustering*) can group customers into segments based on their similarities, even though no prior labels were provided.
