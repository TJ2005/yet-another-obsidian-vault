# Random Forest
A random forest is essentially a collection of [[Decision Tree]]s that run together to classify or predict a value.
- Every Individual Tree has an option of selecting whatever feature they prefer. 
- There is no unseen data here.
- Instead of searching for the most important feature to split a node it searches for the best feature among a random subset of features.
