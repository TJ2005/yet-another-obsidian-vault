## Objective
This lab completes another stage of the data leak case by reviewing evidence for policy violations, file movement, and suspicious communication.

## Case Context
The same suspected insider data leak scenario is examined further to identify evidence of confidential data handling and transfer.

## Tools and Environment
- Autopsy
- Forensic image
- Artifact review
- Timeline analysis
- Case reporting

## Procedure
1. Opened the case evidence in Autopsy.
2. Reviewed file-system artifacts, user activity, and communication traces.
3. Compared findings against the organization's security policy constraints.
4. Prepared screenshots and conclusions for the case report.

## Observations
- Policy context helps interpret whether a discovered artifact is normal activity or suspicious behavior.
- A defensible conclusion should connect the artifact, timestamp, user, and suspected action.
