# Functions
If a variable $y$ depends on a variable $x$ in such a way that each value of $x$ determines exactly one value of $y$ then we say $y$ is a **Function** of $x$

A $function$ $f$ is a rule that associates a unique output with each input if the input is denoted by $f(x)$.

**Four ways to represent functions**
- Numerically ( tables )
- Geometrically ( Graphs )
- Algebraically by formulas
- Verbally
