# Mobile Device Security and Forensics

**Course Code:** 702IT0E019
**Program:** B.Tech CSE Cybersecurity, Semester VI
**Faculty:** Prof. Rejo Mathew
**Credits:** L-T-P-C: 2-0-2-3
Source: 

---

## Course Overview

Mobile Device Security and Forensics focuses on securing mobile platforms and investigating incidents involving smartphones and tablets. It integrates concepts from operating systems, cryptography, networks, and information assurance. 

---

## Course Objectives

* Understand threats faced by mobile devices and their countermeasures
* Perform forensic operations on mobile devices
* Write mobile forensic analysis reports 

---

## Course Outcomes

* **CO1:** Describe mobile threats and countermeasures
* **CO2:** Perform mobile forensic operations
* **CO3:** Write forensic analysis reports 

---

## Units and Topics

### Unit 1: Introduction

* Mobile communication basics
* Cellular coverage and handoff
* GSM, CDMA
* 3G, 4G, 5G networks 

### Unit 2: Security Threats

* Data theft threats
* Device control threats
* System access threats
* Evil twins
* Bluetooth vulnerabilities and countermeasures 

### Unit 3: Mobile Device Security Models

* Android security model
* Android sandbox and file system permissions
* Android SDK security features, rooting, unlocking
* Android permission model
* Apple security model
* iOS sandbox and application provenance
* Encryption, TEE, secure enclaves
* Jailbreaking iOS 

### Unit 4: Mobile Forensics

* Forensic processes and procedures
* NIST forensic framework
* Standard operating procedures
* Evidence collection from scene
* Seizing digital devices
* Mobile forensic tools and report writing 

### Unit 5: SIM Card Analysis

* Smart cards, SIM, UICC
* SIM file system structure
* Network and user data locations 

### Unit 6: Mobile OS Forensics

* Android and iOS forensics
* Application-level forensic investigation
* Impact of rooting/jailbreaking on evidence integrity
* Malware forensics (volatile and non-volatile memory) 

---

## Laboratory Work

* Autopsy and Wireshark (Rhino Hunt)
* Android and iOS analysis
* Memory forensics (LastPass, Keeper)
* ADB and device enumeration
* Andriller, ALEAPP
* Timeline analysis (Plaso)
* Data recovery (PhotoRec)
* MobSF
* Forensic analysis report
