# Overview of information system audit unit 1

Densely networked business model => Dependency on IT => Need for Robust Technology
Protect Internal System from both Internal external threats
To protect Intellectual property => Audit Regularly
IS Contains
- Standards
- Principles
- Guidelines
- Methods
- Practices

IS Auditor uses it to 
- Plan
- Execute
- Assess 
- Review
Business information 

IS Auditor must know auditing process to audit
- IS Processes
- Business Processes
- Business Controls

To achieve organization objectives protect organizational assets

IS Includes audits like
- Financial 
- Operational
- Specializes
- Forensics

Five Type of assets
- Data 
- Application System
- Technology
- Facilities
- People

Seven Attributes of Data

CIAEECR
- Confidentiality
- Integrity
- Availability
- Eficiency
	- Using data in most efficient way
- Effectiveness
	- Data should be relevant and valid
- Compliance
- Reliability

Common Tasks that an auditor 
- Plan
- Conduct
- Communicate
- Evaluate audits
- Guidance
- Improvement suggestion
- Consultation

IS Audit formal examination of systems whether the
- Information system is
	- Legal following regulations
	- Complying to regulations
- Information is CIA
- Information is used Efficiently and Effectively

IT Audit Process has to have
- Planning 
	- SAI says all audit process must be done in high quality, Economic, Efficient Manner
	- Audit Process must be documented and supervised
	- Supervisor should review the documented process
	- The extent and control and scope should be determined before auditing
	- **Strategic Plan**
		- Aim of the audit
		- Resources needed for audit
		- Long term
	- **Macro Plan**
		- Mid Term
		- Program work for long term
	- **Micro Plan**
		- Individual Tasks in detail


- Definition of audit scope and objectives
	- 
- Evaluation of Controls
- Evidence Collection
- Evidence Evaluation
- Report

### Isaca
IS Audit and assurance standards define mandatory requirements that must be met before auditing process.
- IS Auditors must follow ISACA Code of Professional Ethics
- The institutions and management parties must comply
- CISA s should also be designated according to the code
