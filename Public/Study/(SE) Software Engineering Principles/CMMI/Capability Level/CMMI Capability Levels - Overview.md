## What are Capability Levels?
A capability level includes relevant **specific and generic practices** for a specific process area that can improve the organization's processes associated with that process area.

## Continuous Representation
For CMMI models with **continuous representation**, there are **six capability levels** (0-5).

## Purpose
Capability levels allow organizations to improve processes incrementally for individual process areas, rather than across the entire organization at once.

## The Six Levels Summary

| Level | Name                   | Key Focus                                |
| ----- | ---------------------- | ---------------------------------------- |
| 0     | Incomplete             | Process not performed or incomplete      |
| 1     | Performed              | Process works but unstable               |
| 2     | Managed                | Process planned, monitored, controlled   |
| 3     | Defined                | Process standardized across organization |
| 4     | Quantitatively Managed | Statistical control and metrics          |
| 5     | Optimizing             | Continuous improvement                   |

## Key Concept
Unlike Maturity Levels (which apply to the entire organization), Capability Levels apply to **individual process areas**. This allows organizations to have different processes at different capability levels simultaneously.

## Relationship to Maturity Levels
- **Capability Level 0** = Maturity Level 1 (Initial)
- Capability Levels are used in **Continuous Representation**
- Maturity Levels are used in **Staged Representation**
