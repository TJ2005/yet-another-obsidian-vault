# Notes Rag Project
This file is the index of the Notes Rag Project.
## Aim
The main aim of me doing this entire project is to understand the concepts of Vector Database and Retrieval Augmented Generation and the various algorithms that take place in such a project. 

## Outcomes
The table describes the outcomes I want to achieve and its honest status of the project.

| Outcome | Description                                                                                                                      |
| ------- | -------------------------------------------------------------------------------------------------------------------------------- |
| NRP1    | Be able to query my notes database in a manner that a laymen can find relevant notes by typing queries                           |
| NRP2    | Be able to order and rank the results in a manner that the laymen user can actually use the product and not be counter intuitive |
| NRP3    | Build a base to be used in my [[Quartz]] Website so people can actually use the vector database for search                       |
| NRP4    | Augment the Retrieval process with algorithms so an AI LLM can use the relevant parts to respond to part                         |
| NRP5    | Learning purposes                                                                                                                |
