# Capability Level 4: Quantitatively Managed

## Overview
The process is controlled using statistical and quantitative techniques with established objectives.

## Key Characteristics

- Process is controlled using statistical and quantitative techniques
- Process performance and quality is understood in statistical terms and metrics
- Quantitative objectives for process quality and performance are established

## Quantitative Control
At this level, the organization uses statistical process control and other quantitative techniques to manage processes. Performance is measured and analyzed quantitatively, allowing for predictable process outcomes. Quantitative objectives are set and tracked, enabling data-driven decision making and process control.
