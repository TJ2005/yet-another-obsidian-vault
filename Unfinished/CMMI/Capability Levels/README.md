# CMMI Capability Levels Overview

## Purpose
This folder contains detailed documentation of the six CMMI capability levels (0-5), which represent the degree to which a process is institutionalized within an organization.

## Capability Levels

1. **[[Capability Level 0 - Incomplete]]** - Process is incomplete or partially performed
2. **[[Capability Level 1 - Performed]]** - Process performs its intended purpose but may be unstable
3. **[[Capability Level 2 - Managed]]** - Process is planned, monitored, and controlled
4. **[[Capability Level 3 - Defined]]** - Process is standardized across the organization
5. **[[Capability Level 4 - Quantitatively Managed]]** - Process is controlled using statistical techniques
6. **[[Capability Level 5 - Optimizing]]** - Focus on continuous process improvement

## Progression
Each level builds upon the previous one, representing increasing process maturity and organizational capability. Organizations typically progress from [[Capability Level 0 - Incomplete|Level 0]] through to [[Capability Level 5 - Optimizing|Level 5]] as they improve their process management and performance.

## Related Concepts
- Capability levels apply to individual process areas
- Different from maturity levels which apply to the entire organization
- Note: [[Capability Level 0 - Incomplete]] is equivalent to Maturity Level 1
